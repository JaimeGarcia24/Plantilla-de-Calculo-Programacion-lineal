# Plantilla de Cálculo para Programación Lineal

[cite_start]Este proyecto es una plantilla de cálculo interactiva desarrollada como parte de la materia de **Investigación de Operaciones I** [cite: 2] [cite_start]en la Facultad de Ingeniería de la Universidad Autónoma de Campeche. [cite: 1]

[cite_start]El objetivo principal es proporcionar una herramienta web que automatiza la resolución de problemas de Programación Lineal utilizando los métodos Simplex, Dos Fases y de la M. [cite: 5]

## [cite_start]📜 Descripción del Funcionamiento [cite: 28]

La plantilla permite al usuario definir un problema de programación lineal de manera intuitiva y visual. El proceso se divide en los siguientes pasos:

1.  **Definir el Problema**: El usuario especifica el número de variables de decisión y el número de restricciones que tiene su modelo.
2.  [cite_start]**Función Objetivo**: Se ingresan los coeficientes de la función objetivo y se especifica si el objetivo es **Maximizar** o **Minimizar**. [cite: 15]
3.  [cite_start]**Ingresar Restricciones**: Se introducen los coeficientes de cada restricción, se selecciona el signo de la desigualdad (`<=`, `>=`, `=`) y se define el valor del lado derecho (RHS). 
4.  [cite_start]**Resolver**: El usuario selecciona el método de solución deseado (Simplex, Dos Fases, o Método de la M) [cite: 12] y presiona el botón "Resolver".
5.  [cite_start]**Visualizar Resultados**: La aplicación muestra el procedimiento **paso a paso** en forma de tablas para cada iteración del algoritmo. [cite: 17] [cite_start]Al final, se presenta de forma clara la **solución óptima**, incluyendo el valor de la función objetivo y los valores de las variables de decisión. [cite: 19, 20]

## [cite_start]🚀 Instrucciones de Ejecución [cite: 29]

Esta plantilla es una aplicación web autocontenida y no requiere de un servidor o dependencias complejas para funcionar.

Para ejecutarla, simplemente sigue estos pasos:

1.  Clona o descarga este repositorio en tu computadora.
2.  Navega a la carpeta del proyecto.
3.  Abre el archivo `index.html` en cualquier navegador web moderno (como Google Chrome, Firefox, o Microsoft Edge).

La aplicación se cargará y estará lista para ser utilizada.
